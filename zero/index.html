Password Check

Measures strength here on your machine, then checks whether it appears in public breach data.

Your password is never sent. It is hashed on this device and only the first five characters of that hash go out. The service replies with every suffix sharing that prefix and the match is made here — so it never learns which one you asked about. That is the only reason this check is acceptable to build.

Scope

          
Zero's security tooling is defensive: it hardens things you own and control. It contains no scanner, no exploit and no payload, and I won't add them — a tool built to break into other people's systems is a liability to whoever owns it first, and every serious security professional works inside written authorisation. If you're doing authorised testing, the real toolchain lives outside a browser tab anyway.

Quick add:

          

          

            
            
            
          

          
What this is and isn't. A web page cannot reach inside other programs — that boundary is precisely why a browser is safe to open. Zero Core — Any AI core

            
Give Zero a brain. Pick Local engine to stay fully private, or pick a provider and paste an API key to make Zero use any AI you tell it to.


            
            

            
            

              
              
              
              
            


            
            

              
              
            


            
            

            
            

            

              
              
              
            

            

            

              Three ways to give Zero a brain.

              1 · Local model (fully private): Ollama, llama.cpp, LM Studio, Jan. For Ollama: OLLAMA_ORIGINS=* ollama serve.

              2 · Any AI by API key (right here): choose the provider above, paste your key, set the model, Save & test. The key lives on this device only. Your prompts go straight to that provider — some (OpenRouter, Groq, Anthropic, most “compatible” hosts) allow the browser to call them directly; if a provider blocks browser calls, use option 3.

              3 · Python bridge: run python3 server.py with the key set server-side, then Use bundled bridge. Works with every provider.
            

          


          

            
Vault off

            
Encrypts your tasks and notes on this device with a passphrase. Without it, anything Zero saves can be read by anyone who reaches this browser profile or a backup of it.


            

              
              
              
              
              

              
There is no reset. The passphrase is never stored, so nobody — including Zero — can recover your data without it. Write it down somewhere safe before you continue.

            


            

              

                
                
              

              
Locking wipes the key and your data from memory. Zero keeps running; the saved data stays sealed until you unlock it again. Panic on the Control Panel does this instantly.
