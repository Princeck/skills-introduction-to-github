Your Apps

Add anything the operating system can open — a website, or an app link like vscode://, figma://, spotify:. Then say open figma in chat and Zero launches it.

What this is and isn't. A web page cannot reach inside other programs — that boundary is precisely why a browser is safe to open. What Zero can do is hand a link to your operating system and let it choose the app, which is how every deep link works. Launching: yes. Controlling: no, and anything claiming otherwise in a browser tab is misleading you.

Memory

Facts Zero carries into every future conversation. Say remember <something> in chat to add one, forget 2 to drop one.

Memories are stored with your tasks and notes — encrypted when the vault is on, and dropped from memory the moment it locks.

Storage

Zero keeps everything in a local database on this device — hundreds of megabytes rather than the ~5 MB a browser allows the simpler store.

Zero Core no account

Core is Zero's reasoning engine. It drives a model on this machine — no vendor, no sign-in, no key. Prompts go to the address below and nowhere else.

Running an engine. Core works with any local runtime that speaks one of the two formats above — Ollama, llama.cpp, LM Studio and Jan all do. These are open-source runtimes you install yourself, not hosted services. Serving Zero from a file means the runtime must be told to accept it: for Ollama that is OLLAMA_ORIGINS=* ollama serve, otherwise the browser blocks the request and a working engine looks dead.

Vault off

Encrypts your tasks and notes on this device with a passphrase. Without it, anything Zero saves can be read by anyone who reaches this browser profile or a backup of it.

There is no reset. The passphrase is never stored, so nobody — including Zero — can recover your data without it. Write it down somewhere safe before you continue.
Locking wipes the key and your data from memory. Zero keeps running; the saved data stays sealed until you unlock it again. Panic on the Control Panel does this instantly.
